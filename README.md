## Descripción del proyecto
<p>Proyecto desarrollado como parte del desafío para el curso Oracle Next-One, en colaboración con Alura LATAM</p>
<p>Esta aplicación permite realizar la conversion de distintas monedas en tiempo real, con la ayuda de ExchangeRateAPI </p> 
<p> https://www.exchangerate-api.com </p>
<p align="center"><img src="https://github.com/user-attachments/assets/895a98de-e2e4-40d7-85bd-67a3e934a232"></p>


## Funcionalidades

:triangular_flag_on_post: `Funcionalidade 1:` Solicitar la moneda que desea convertir 

:triangular_flag_on_post: `Funcionalidad 2:` Seleccionar la moneda a la que desea convertir

:triangular_flag_on_post: `Funcionalidad 3:` Seleccionar la cantidad a convertir
